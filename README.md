# Publisher API

**Publisher API** — это RESTful API-сервис, предназначенный для управления и публикации JSON-документов с разграничением прав доступа пользователей. Проект построен на современном и производительном стеке технологий с использованием контейнеризации Docker.

---

## 🛠 Технологический стек

* **Язык программирования:** PHP 8.4 (FPM)
* **Фреймворк:** Symfony 8.1.*
* **База данных:** PostgreSQL 16 (Alpine)
* **Веб-сервер:** Nginx (Alpine)
* **Аутентификация:** JWT (JSON Web Token) посредством установки авторизационной HTTP-куки
* **Качество кода:** PHPStan (уровень 6) для статического анализа

---

## 🐳 Быстрый старт в Docker

Проект полностью готов к разворачиванию в Docker. По умолчанию приложение будет доступно на локальном хосте на порту `8080`.

### 1. Сборка и запуск контейнеров
Соберите Docker-образы и запустите сервисы в фоновом режиме:
```bash
docker compose up -d --build
```

### 2. Инициализация базы данных и миграции
Создайте схему базы данных и примените все существующие миграции Doctrine:
```bash
docker compose exec php bin/console doctrine:database:create
docker compose exec php bin/console doctrine:migrations:migrate -n
```

### 3. Подготовка тестового окружения
Создайте базу данных для запуска автотестов:
```bash
docker compose exec php bin/console doctrine:database:create --env=test
docker compose exec php bin/console doctrine:migrations:migrate -n --env=test
```

## 🧑‍💻 Инструменты разработки и тестирования

Все команды выполняются внутри изолированного контейнера `php` с использованием Composer-скриптов.

* **Запуск автотестов (PHPUnit):**
  ```bash
  docker compose exec php composer test
  ```
* **Запуск статического анализа кода (PHPStan):**
  ```bash
  docker compose exec php composer phpstan
  ```
* **Очистка кэша Symfony:**
  ```bash
  docker compose exec php bin/console cache:clear
  ```

## 📑 Спецификация API (Endpoints)

Все запросы к закрытым эндпоинтам требуют наличия Bearer JWT-токена в заголовках или авторизационной куки.

### 🔐 Аутентификация

| Метод | Путь | Описание | Доступ |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/auth` | Аутентификация пользователя (выпуск JWT-куки) | Публичный |
| `GET` | `/api/v1/profile` | Получение данных текущего пользователя | Авторизованный |

### 📄 Управление документами

| Метод | Путь | Описание | Права (Voter) |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/v1/document` | Получение списка опубликованных документов с пагинацией | Авторизованный |
| `POST` | `/api/v1/document` | Создание нового JSON-документа (черновика) | Авторизованный |
| `GET` | `/api/v1/document/{id}` | Получение полной информации о документе по ID | Владелец / Публичный |
| `PUT` | `/api/v1/document/{id}` | Редактирование существующего документа | Только Владелец |
| `DELETE`| `/api/v1/document/{id}` | Удаление документа по его ID | Только Владелец |
| `POST` | `/api/v1/document/{id}/publish` | Публикация документа (перевод из черновика) | Только Владелец |
